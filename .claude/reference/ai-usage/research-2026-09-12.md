## A. GitHub spec-kit

## B. Context and token efficiency

### B1. CLAUDE.md and AGENTS.md

- Discovery and precedence: managed policy, `~/.claude/CLAUDE.md`, `./CLAUDE.md` or `./.claude/CLAUDE.md`,
  `./CLAUDE.local.md`; all concatenated; subdirectory files load on demand. https://code.claude.com/docs/en/memory
- "Claude Code reads `CLAUDE.md`, not `AGENTS.md`"; use `@AGENTS.md` or a symlink. Same page.
- AGENTS.md open standard, Agentic AI Foundation under the Linux Foundation, no size guidance. https://agents.md/
- "Target under 200 lines per CLAUDE.md file. Longer files consume more context and reduce adherence."
  https://code.claude.com/docs/en/memory and https://code.claude.com/docs/en/costs#reduce-token-usage
- Include: commands Claude cannot guess, style rules that differ from defaults, test instructions, repo
  etiquette, architectural decisions, environment quirks, gotchas. Exclude: anything derivable from code,
  standard conventions, API docs, frequently changing facts, tutorials, file-by-file descriptions. Test per
  line: "Would removing this cause Claude to make mistakes?" https://code.claude.com/docs/en/best-practices
- "If you emphasize many lines, none of them stands out." Same page.
- Three tiers: CLAUDE.md for every session, `.claude/rules/*.md` with `paths:` for part of the tree, skills for
  procedures. `@path` imports load at launch and do not reduce context. https://code.claude.com/docs/en/memory
- `/init`, `/import`, `/memory`, `/context` ("Memory files"), `/doctor` proposes trims of derivable content,
  `InstructionsLoaded` hook logs what loaded. https://code.claude.com/docs/en/memory, https://code.claude.com/docs/en/commands
- "Treat CLAUDE.md like code ... test changes by observing whether Claude's behavior actually shifts."
  https://code.claude.com/docs/en/best-practices
- HumanLayer: under 300 lines, theirs under sixty; "Never send an LLM to do a linter's job"; do not
  auto-generate with `/init`; use `file:line` references instead of code snippets; instruction following
  degrades uniformly as instruction count grows. https://www.humanlayer.dev/blog/writing-a-good-claude-md
- Anthropic on context rot and "the smallest possible set of high-signal tokens".
  https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents

### B2. Prompt caching

- Layers: system prompt and tools, then project context, then conversation; exact prefix matching; no per-file
  caching. https://code.claude.com/docs/en/prompt-caching
- TTL: 5 minutes or 1 hour. Main conversation gets 1 hour on a subscription within plan usage; subagents,
  teammates, forks and compaction get 5 minutes unless `subagentPromptCacheTtl` or
  `CLAUDE_CODE_SUBAGENT_PROMPT_CACHE_TTL` is set (v2.1.242+), or `cacheTtl` in agent `experimental`
  frontmatter (v2.1.248+). https://code.claude.com/docs/en/prompt-caching#cache-lifetime
- Cost: 5-minute write 1.25x, 1-hour write 2x, read 0.1x (0.025x on Fable 5.1).
  https://platform.claude.com/docs/en/about-claude/pricing#prompt-caching
- Invalidates: model switch (including `opusplan` on every plan-mode toggle), effort change, first fast-mode
  turn, MCP server connect or disconnect when tools are in the prefix, plugin toggles, `/compact`, image
  eviction, upgrading Claude Code. Keeps: file edits, CLAUDE.md edits mid-session, permission mode, skills,
  `/rewind`, spawning a subagent. https://code.claude.com/docs/en/prompt-caching#actions-that-invalidate-the-cache
- Cache is per machine and per directory; worktrees do not share.
- "Prompt caching is everything." https://claude.com/blog/lessons-from-building-claude-code-prompt-caching-is-everything
- `/usage` shows a `Prompt cache (main)` line with hit share and likely cause of the last miss (v2.1.251+).
  https://code.claude.com/docs/en/costs#prompt-cache-statistics

### B3. MCP servers

- Five servers measured at ~55K tokens before the conversation; tool search cut ~77K to ~8.7K.
  https://www.anthropic.com/engineering/advanced-tool-use
- Claude Code defers MCP tool definitions by default; `ENABLE_TOOL_SEARCH` values unset, `true`, `auto`,
  `auto:N`, `false`. https://code.claude.com/docs/en/agent-sdk/tool-search
- "Prefer CLI tools when available" and "Disable unused servers".
  https://code.claude.com/docs/en/costs#reduce-mcp-server-overhead

### B4. Subagents

- A subagent starts with its own system prompt, the delegation message, its own copy of CLAUDE.md, a git
  snapshot and preloaded skills. https://code.claude.com/docs/en/sub-agents
- Return "condensed, distilled summary of its work (often 1,000-2,000 tokens)".
  https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents
- Agent teams use about 7x the tokens of a standard session; use Sonnet for teammates, keep teams small, keep
  spawn prompts focused. https://code.claude.com/docs/en/costs#agent-team-token-costs
- `Explore` and `Plan` skip CLAUDE.md. https://code.claude.com/docs/en/context-window

### B6. Codemaps versus search

- Aider repo map: symbols and signatures ranked by a dependency graph, default budget 1,000 tokens,
  generated per request. https://aider.chat/docs/repomap.html
- Anthropic: lightweight identifiers loaded at runtime, progressive disclosure.
  https://www.anthropic.com/engineering/effective-context-engineering-for-ai-agents
- Best-practices exclude list names "File-by-file descriptions of the codebase"; `/doctor` cuts directory
  layouts, dependency lists and architecture overviews. https://code.claude.com/docs/en/best-practices
- Code intelligence plugins replace grep-then-read chains; a codebase-overview skill loads on demand.
  https://code.claude.com/docs/en/costs

### B7. Measuring

- `/usage`: session cost, per-model tokens, cache line; on paid plans breakdown by skill, subagent, plugin and
  MCP server. https://code.claude.com/docs/en/costs#track-your-costs
- `/context`: live breakdown with which memory files loaded. https://code.claude.com/docs/en/context-window
- OpenTelemetry: `CLAUDE_CODE_ENABLE_TELEMETRY=1`, `OTEL_METRICS_EXPORTER=otlp`; metrics
  `claude_code.token.usage` and `claude_code.cost.usage` with `model`, `effort`, `agent.name`, `skill.name`,
  `mcp_server.name`. https://code.claude.com/docs/en/monitoring-usage
- `ccusage` reads local JSONL. https://github.com/ryoppippi/ccusage
- `/insights` report; reference figures about $13 per developer per active day. https://code.claude.com/docs/en/costs

### B8. Hooks

- Plain stdout enters context only for `UserPromptSubmit`, `UserPromptExpansion`, `SessionStart`,
  `PostModelSwitch`; PreToolUse and PostToolUse stdout goes to the debug log; `additionalContext` is the
  deliberate injection channel; exit 2 stderr surfaces to Claude. https://code.claude.com/docs/en/hooks
- Hooks as filters: grep a log for errors instead of reading it.
  https://code.claude.com/docs/en/costs#offload-processing-to-hooks-and-skills
- Hooks are deterministic where CLAUDE.md is advisory. https://code.claude.com/docs/en/best-practices
